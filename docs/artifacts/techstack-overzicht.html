3 · Orkestratie — het verschil, en de keuze

Besloten: A

Besluit: A — Trigger.dev, omdat de runtime TypeScript blijft. Cloud nu (de motian-tasks porten in dagen); self-host pas als de rekening structureel boven ~$150–200 komt. De $230–250 in het diagram was gerekend op 6M fetches (recheck per vacature); de bronmatrix — polling op listings, detail alleen bij gewijzigde hash — komt op ~1–1,2M en dus ~$50–100/mnd. Wat we uit optie B wél meenemen: fan-out per bron via batchTrigger met concurrencyKey, idempotencyKey per (bron, sweep), ttl, per-task maxDuration — dat levert JI-ING-02 ("één trage bron houdt nooit de rest vast") zonder Temporal's leercurve. Temporal blijft de gedocumenteerde route als er ooit Go/Rust-workers komen.

7 · Bewezen patronen — kopiëren op dag één

Geleerd

Deze patronen komen uit een productie-platform dat hetzelfde probleem al een jaar oplost — agents en mensen op één tool-oppervlak, effecten achter goedkeuring — inclusief de littekens. Eén nuance: dat platform dwingt layering af met CI-guards in plaats van met Effect-TS. De Effect-keuze blijft; de guards komen erbij, want ze bewaken wat een typesysteem niet ziet.

Patronen — letterlijk overnemen

  • Capability registry (packages/application/registry/): één entry per gebruikersuitkomst, gebonden aan één handler, met sideEffectClass: read | proposal | commit, approval, auditClass, idempotency, wiredTransports[]. UI, REST en MCP zijn adapters die het id refereren — nooit eigenaar van gedrag. Dit ís §4: approval is data op de capability, met een verplichte reden om eruit te stappen.
  • Bidirectionele drift-gates: check-capability-registry faalt als een adapter ontbreekt ("een gepland transport kan nooit uitvoerbaar lijken"); check-capability-coverage faalt als een UI-actie geen agent-pad heeft. Dat is agent-native pariteit (G2) mechanisch afgedwongen.
  • Proposal → acceptance → commit, getypeerd: acceptanceEvent {accepted: true, acceptedBy, acceptedAt}, commitInput {proposal, acceptance?, idempotencyKey}, gesloten error-enum incl. acceptance_required. Doctrine: "MCP is protocol aan de rand; de applicatiegrens is een getypeerde interne tool-registry."
  • mock / sandbox / real voor elke externe provider — contract-suite draait altijd op mock; "de app boot en slaagt met alleen mocks." Voor ons: elke job-board-connector, Manticore, Spott.io.
  • Boundary-guards zonder allowlist; waar schuld al bestaat een krimpende allowlist (gemigreerd-maar-nog-gelist faalt ook). Plus check-phantom-delegation (~40 regels): blokkeert commentaar dat een component gedrag toedicht dat nergens bestaat.
  • Visual evidence als merge-gate: Playwright video: 'on', één test per claim, H.264/MP4, nooit op productbranches.
  • Repo bezit het waarom: docs/decisions/-register met ADR-promotie, docs/PROGRESS.md append-only incl. "wat je bewust níet deed".

Anti-patronen — gedocumenteerd, dus vermijdbaar

  • "De dialect-flag was een fout": een tweede database achter een DB_DIALECT-vlag werd na een jaar ingetrokken en verboden. Voor ons: Postgres en Manticore zonder engine-abstractie. De SearchAdapter is een vervangings-naad (één actieve implementatie, AST-emitter), geen gelijktijdige-engines-laag — anders wordt hij de dialect-flag.
  • Migraties die alleen op een lege DB werken: CI migreert een verse tenant, dus de backfill draait over nul rijen; live incident: een migratie dropte kolommen en Drizzle's db.select() emitteert élke schema-kolom → column does not exist op echte tenants. Voor ons: migratietests op een gevulde fixture (JI-005-import), en assert dat een echte select resolvet, niet alleen metadata.
  • Groen is geen bewijs: een slice slaagde met 1.290 ongewijzigde tests terwijl een echte API-gedragswijziging in de diff zat; alleen de opname liet het zien. "Een refactor die inert claimt te zijn is niet vrijgesteld."
  • Tracker-automatisering liegt over deelwerk: een PR "slice 1" zette een tien-criteria-ticket op Done. Mitigatie: verplichte ## Partial-sectie + check.
  • Score-drempels zijn onbruikbaar als gate: één slordig bestand verschoof de boomscore 100→97 van 1.625 bestanden. Gate op error-level bevindingen in gewijzigde bestanden; backlog zichtbaar via SARIF.
  • Directe DB-toegang in routes groeide 25→33 op één dag — groei, niet omvang, maakt het onbegrensd. Vandaar de ratchet.

Niet overnemen: een gegenereerde wiki (vraagt een volwassen boom), een duizenden-regels capability-bestand vooraf (laten groeien), en worktree-wildgroei.

8 · Wat nu vastligt, wat open staat

Besluiten

Vast

  • Bun/TS/Effect; motian-scrapers hergebruikt; alle 28 connectors in eigen beheer op de per-bord ladder
  • Trigger.dev als orkestratie (TS-runtime); Cloud nu, self-host ingepland; fan-out per bron met idempotency-keys
  • DuckLake als analytics/export-laan naast Postgres-marts; capability registry + drift-gates vanaf dag één
  • Hetzner + Coolify; Chromium on-box; Browserbase/Firecrawl per vijandig bord
  • Postgres SoR met zones + outbox; Manticore achter SearchAdapter; Redis voor rate-limit + geversioneerde cache
  • API + MCP als enig datapad; approval-beleid als data; score + reden vanaf dag één
  • 600k/mnd is de ontwerpschaal; JI-NFR-02 aangescherpt naar p95 ≤ 100 ms

Open — jouw besluit

  • Postgres: Neon blijven tot ~7,5M of meteen on-box (Manticore-buffers, ParadeDB-optie, latency naar drainer)
  • DEC-002 bronmatrix — geverifieerd: 29 rijen = 23 echte bronnen (docs/SOURCE_MATRIX.md); 12 publiek via feed/API/JSON-LD (rung 1–2, geen browser), 6 achter eigen leveranciersaccount, 4 invitation-only/geblokkeerd (Magnit, Randstad — ToS verbiedt, Circle8 — Vercel-challenge, OneStopSourcing — geen DNS). Nog nodig van Robbie: accounts (Striive, StaffingNow, Mercell, Circle8) en ToS-besluiten (Mercell robots, Striive 4.6). TenderNed-recept staat in docs/sources/tenderned.md.
  • Spott.io-contract: naam/URL, API of MCP, write-scope, sandbox (DEC-006)
  • Requirements-herschrijving: JI-DAT-01 (Pydantic→Effect Schema), JI-INT-01 (FastAPI→Effect HTTP), JI-OPS-07 (Alembic→Drizzle), JI-ING-02 (SKIP LOCKED→queues), JI-DAT-08/JI-SRC-01 (tsvector→SearchAdapter), JI-INT-04 (push via approval-snapshot)
