Open gaps & bewuste keuzes

RJC-403
Launch-evidence gesplitst

Canaray-browser/release-SHA-bewijs is gescheiden van echte-data-completeness (aggregaten, ID-digest). Beide zijn nodig vóór launch-claim.

RJC-404
Neon Free 512 MB

Backfill stopte bij ~62k rijen (53100 project limit). Volledige Motian-import (~252k) vereist betaald Neon-plan of reclaim + opschoning.

DNS
Cutover open

api/app.catapulze.com wijst nog naar TransIP (). Rehearsal liep op sslip.io; definitieve A-records + auth-URL's wachten op GO.

Curate
contentHash outbox-skip

Statuswijziging zonder nieuwe hash schrijft geen outbox-event → projector slaat over. Reparatie via search:reconcile-projection.

Ingest
Parallel curateScrapeRun

Observaties worden sequentieel verwerkt (no-await-in-loop). Parallel curate is gepland voor backfill-throughput, niet live.

Process
Linear hygiene

Issue-status, partial-AC's en GitHub–Linear-automatisering moeten synchroon blijven met werkelijke deploy-bewijs — geen Done zonder AC-dekking.

Architectuur
Geen Kafka / RabbitMQ

Bewuste keuze: Postgres-outbox + projector i.p.v. message broker. Outbox in dezelfde transactie als curated writes; geen extra bewegende delen.

Agent-ops
SSH + restore voor agent

Cloud agents bereiken Hetzner via SSH/Tailscale + runbooks (restore, migrate, projector). Geen publieke Coolify-8000; operator-credentials in 1Password.

live in productie partial deels / gated planned ontwerp / backlog blocked blokkeert cutover
